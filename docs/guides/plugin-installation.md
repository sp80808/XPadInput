# Plugin Installation

XPadInput provides AUv3 and VST3 plugins that you can load directly inside your DAW (Logic, Ableton, Bitwig, etc.).

## Auto-Installation
The easiest way is to use the onboarding prompt or the settings menu in XPadInput to automatically place the plugins into the correct system folders.

## Manual Installation
If you prefer to install manually, the compiled plugin bundles are located in the build directory.

Copy them to:
- **Audio Unit (.component):** `~/Library/Audio/Plug-Ins/Components/`
- **VST3 (.vst3):** `~/Library/Audio/Plug-Ins/VST3/`

Restart your DAW or rescan plugins for them to appear.
