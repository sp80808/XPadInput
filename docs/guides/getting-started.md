# Getting Started

XPadInput turns any compatible game controller into an expressive MPE MIDI instrument.

1. **Connect** your DualSense, Xbox, or Switch Pro controller via USB or Bluetooth.
2. **Launch** XPadInput. The controller icon should pulse green indicating it's connected.
3. **Play** by moving the left analog stick (to select chords) and sweeping the right analog stick (to strum).
4. **Connect to DAW** by toggling "Virtual MIDI" in the bottom transport bar.

Explore the UI for more advanced options like the Harmony workspace, scale adjustments, and built-in synthesizer.
