# Controller Setup

XPadInput maps gamepad controls to musical parameters.

## Support
Supported controllers out-of-the-box include:
- Sony DualSense & DualShock 4
- Microsoft Xbox Controllers (Bluetooth/USB)
- Nintendo Switch Pro Controller
- MFi certified iOS gamepads

## Mapping Overview
- **Left Stick:** Selects diatonic chords
- **Right Stick:** Strums strings or triggers notes (velocity is based on swipe speed)
- **Face Buttons:** Shapes the chord quality (e.g. 7ths, 9ths, extensions)
- **Triggers (L2/R2):** Pitch bend or expression control
- **Gyroscope:** If available, modulates timbre (CC74) and vibrato via tilt
